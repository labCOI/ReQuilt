# Weights

Place the fine-tuned detector here as `requilt_yolov8n.pt`.

* **Download:** see the [Releases](../../../releases) page of this repository.
* **Or train it yourself:** run `notebooks/05_finetune_detector.ipynb`. It copies the best checkpoint here.

`*.pt` files are git-ignored. Keep weights out of the repository and publish them as Release assets.
